# Нативный ABI v1

- Пользовательские функции: `yadro_fn_<имя>`.
- Нативная обёртка владеет символом `main`.
- Системные API: `yadro_ext_v1_<qualified_name>`, точки заменяются подчёркиваниями.
- Параметры и возвраты используют signed i64; bool zero-extend на границе.
- `main`, `printf` и имена с `ext.` зарезервированы.
- Один extern-символ имеет ровно одну сигнатуру в модуле.
- String ABI ещё не стабилен; поддерживается прямая печать строк.
