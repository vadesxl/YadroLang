# Система типов YadroLang

До LLVM CodeGen каждому выражению выводится минимальный статический тип.

- `i64`: целые, арифметика, системные API и legacy fallthrough.
- `bool`: `истина`, `ложь`, равенство и сравнения.
- `string`: строковые литералы и переменные; сейчас поддерживается `печать`.

Арифметика принимает только `i64`. Сравнения возвращают `bool`. Параметры и возврат функций выводятся по call graph, включая рекурсию. Присваивание не может менять тип переменной. Код после безусловного `вернуть` запрещён.

Для обратной совместимости `если` и `пока` принимают `bool` и legacy `i64` truthiness: 0 означает ложь, ненулевое значение истину. Строки условиями быть не могут.
