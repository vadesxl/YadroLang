# Участие в разработке YadroLang

Спасибо за интерес к проекту YadroLang!

## Как помочь

### Баг-репорты

1. Проверьте существующие [issues](https://github.com/vadesxl/YadroLang/issues)
2. Откройте новый issue с:
   - Понятным заголовком и описанием
   - Шагами для воспроизведения
   - Ожидаемое vs фактическое поведение
   - Версия YadroLang и ОС

### Отправка изменений

1. Сделайте форк репозитория
2. Создайте ветку: `git checkout -b feature/моя-фича`
3. Внесите изменения
4. Убедитесь что CI проходит: все примеры в `examples/` должны компилироваться или отклоняться как ожидается
5. Отправьте Pull Request

### Добавление тестов

Новые примеры `.яд` всегда приветствуются! Размещайте их в `examples/` и добавляйте соответствующие шаги CI в `.github/workflows/run.yml`.

### Стиль кода

- Python код: PEP 8
- Примеры YadroLang: используйте описательные имена файлов (например, `неявный_поток_утечка.яд`)
- Комментарии на русском для этого репозитория

## Структура проекта

```
src/
  лексер.py      - Токенизатор
  синтаксис.py   - Парсер (AST)
  этика.py       - Этический анализатор v2.0
  кодоген.py     - Генератор LLVM IR
  main.py        - Точка входа CLI
examples/        - Тестовые примеры (.яд файлы)
std/             - Стандартная библиотека
```
