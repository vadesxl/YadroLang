# Спецификация policy v1.0

Policy является UTF-8 JSON с `version`, `sources`, `sinks`, `sanitizers`.
- `sources`: символ -> встроенная метка.
- `sinks`: символ -> требуемый capability.
- `sanitizers`: символ -> метки, которые разрешено снять.
- Метки: `ПДн`, `Финансы`, `Здоровье`, `УчетныеДанные`, `Локация`.

Custom entries действуют только один CLI-вызов и затем сбрасываются. Неверные версии, shapes и labels отклоняются fail-closed. Зарезервированные символы нельзя переопределять исходником. Совместимость следует major-версии формата.
