# Статус возможностей

## Implemented
Функции, переменные, рекурсия, if/else, while, вывод ц64/bool, прямая печать строк, LLVM IR/native object, capability mandates, explicit/implicit multi-label, strict declassification, JSON/SARIF CLI, custom JSON policy, Yadro MCP tool graph, CI на трёх ОС.

## Experimental
Вывод типов на recursive call graph, MCP excessive-agency heuristic, audit evidence, external ABI v1, opt-in checked signed i64 arithmetic profile.

## Planned
Runtime ABI library, signed evidence, framework adapters, packaging/binaries, полноценная string/memory model, накопленный checked-arithmetic benchmark baseline.

## Not supported
GC, VM/interpreter, произвольный MCP import, dynamic policy, хранение/возврат строк, полное ownership, saturating arithmetic, recovery после arithmetic trap, microarchitectural proof.
