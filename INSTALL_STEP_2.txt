==================================================
ШАГ 2: УСТАНОВИТЬ NODE.JS
==================================================

Откройте PowerShell как Администратор
(Нажми Win+X, выбери "Windows PowerShell (Admin)")

Скопируй и вставь эту команду:

winget install OpenJS.NodeJS

Ждите 2-3 минуты пока устанавливается.

После этого проверь еще раз:

node --version

Должно вывести версию типа v18.0.0
