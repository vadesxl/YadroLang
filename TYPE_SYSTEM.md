# Выводимая система типов YadroLang

YadroLang сохраняет лаконичный синтаксис и выводит `ц64`, `булево`, `строка` и внутренний `неизвестно`.

- Числа и системные API имеют тип `ц64`.
- `истина` и `ложь` имеют тип `булево`.
- Арифметика требует `ц64`, сравнения возвращают `булево`.
- `если` и `пока` принимают `булево` и совместимое legacy-правило truthiness для `ц64`: ноль ложен, остальное истинно.
- Строки пока разрешены только как прямые литералы `печать("...")`.
- Типы параметров и возвратов выводятся до фикспойнта; смешанные возвраты запрещены.
- Функция без `вернуть` сохраняет совместимый неявный `вернуть 0`.
- Код после безусловного `вернуть` недостижим и отклоняется.

LLVM ABI v1 нормализует `булево` в `ц64` на границах переменных, вызовов и возвратов, сохраняя `i1` для промежуточных сравнений.
