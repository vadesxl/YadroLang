# Система типов YadroLang

Строгий semantic layer использует `i64`, `bool` и `string`.

- Арифметика принимает только `i64`.
- Сравнения `i64` возвращают `bool`.
- Условия принимают `bool`; для совместимости разрешён i64 truthiness: `0` ложь, остальное истина.
- Параметры функций пока используют стабильный ABI v1 `i64`.
- Возврат выводится и обязан совпадать на всех путях.
- `bool` понижается в `i64` на ABI-границе.
- Строки пока разрешены только как прямой аргумент `печать`; хранение и возврат отклоняются до стабилизации string ABI.
- Код после безусловного возврата запрещён.
