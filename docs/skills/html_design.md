# Навык: дизайн HTML-отчётов и виджетов Yadro Guard

Переиспользуемые правила, чтобы любой отчёт/виджет выглядел как часть дорогого
продукта и совпадал по стилю с дашбордом Hermes Orbit.

## 1. Палитра (Hermes Orbit, тёмная тема)
- Фон страницы: `#0b0e14`; радиальный градиент-подсветка сверху: `#1b2336`.
- Поверхность карточки: `#11151f`, граница `#222a3a`, радиус 12–16px.
- Текст: основной `#e8ebf2`, приглушённый `#7f8aa3`, тусклый `#566079`.
- Акценты по смыслу: опасность `#e0533d`, успех `#3ec46d`, секрет/источник `#8a5cf6`,
  финансы `#e8a33d`, здоровье `#d14fa0`, локация `#2f9fd8`.
- Шрифты: UI — `system-ui, Segoe UI`; код/значения — `ui-monospace, Consolas`.

## 2. Фирменные приёмы Hermes
- Подпись секции капсом, моноширинно, с префиксом `-- ` и трекингом букв.
- Статус точкой-кружком со свечением (`box-shadow:0 0 12px currentColor`).
- Крупные моноширинные значения (часы, счётчики).
- Пустое состояние: тусклая строка `● no data`, а не пустота.
- Плотная сетка карточек (grid), одинаковые отступы 14–18px.

## 3. Правила самодостаточности (обязательно для инструмента безопасности)
- Один `.html` файл. Без JS, без внешних шрифтов/картинок/CDN.
- Строгий CSP в `<meta>`: `default-src 'none'; style-src 'unsafe-inline'`.
- ВЕСЬ пользовательский текст (код, пути, сообщения) — через `html.escape(.., quote=True)`.
  Отчёт по чужому коду не должен исполнять чужой скрипт. Это проверяется тестом.
- Внизу — строка доверия: «Отчёт создан локально. Данные никуда не отправлялись.»

## 4. Язык отчёта — человеческий, не коды
- Метку `Здоровье` показывать как «🏥 Медицинские данные» + пояснение про закон.
- Сток `сеть.отправить` — как «отправку в сеть».
- Всегда давать «что делать»: блок Карантин со списком разрешённых обёрток.
- Код ошибки (`ЯДРО-Э2301`) — мелким в углу, для техспециалиста, не как заголовок.

## 5. Структура отчёта (порядок блоков)
1. Шапка: бренд + точка-статус + путь/время/версия.
2. Hero-вердикт: иконка, крупный заголовок по-русски, подзаголовок-пояснение, код в углу.
3. «Что утекает» — карточки меток.
4. «Путь данных» — узлы источник → … → сток со стрелками.
5. «Карантин» — как отправить легально.
6. «Было / стало» — автоисправление (diff).
7. Техническое сообщение (моноширинный блок).
8. Исходный код с подсветкой строк (красная — утечка, фиолетовая — источник).

## 6. Реализация в коде
- Весь HTML собирается в `src/report_html.py`, функция `построить(...)`.
- CSS — одной строкой-константой `СТИЛЬ`, встраивается в `<style>`.
- Встраиваемый фрагмент для дашборда: `виджет(...)` — тот же стиль, но без `<html>`,
  чтобы Hermes мог вставить его в карточку через iframe srcdoc или контейнер.

## 7. Чек-лист перед коммитом
- [ ] Нет `<script`, нет `http://`/`https://` ссылок на ресурсы.
- [ ] Есть CSP-мета.
- [ ] XSS-тест зелёный (вредный ввод экранируется).
- [ ] Открывается офлайн в чистом профиле браузера.
- [ ] Выглядит как карточка Hermes (палитра, подписи-капс, точка-статус).
